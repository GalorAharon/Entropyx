# Entropyx 🚀

A comprehensive, interactive penetration testing cheatsheet and reference guide designed for offensive security practitioners, CTF players, and red teamers. 

Features a clean, custom dark purple hacker-themed web interface for quick command lookup and methodology execution during security assessments.

---

## 🔥 What's Inside

- **Reconnaissance & Scanning:** Quick reference commands for network discovery and enumeration (Nmap, Gobuster, etc.).
- **Exploitation & Post-Exploitation:** Linux privilege escalation vectors, Active Directory assessment commands, and payload generation.
- **Web Application Security:** Practical checklists and workflows for identifying and exploiting web vulnerabilities.
- **DFIR & Malware Analysis:** Core commands and triage steps for digital forensics and incident response.
